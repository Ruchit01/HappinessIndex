# HappinessIndex
A data analysis and machine learning project exploring the World Happiness datasets from 2015 to 2019.

The project includes:

1) Data loading and preprocessing using Pandas
2) Exploratory data analysis and visualization using Matplotlib
3) Correlation analysis between numerical features
4) Feature normalization and train-test splitting
5) Implementation of Linear Regression from scratch
6) Evaluation using Mean Squared Error (MSE) and R² score
7) Comparison with Scikit-learn's Linear Regression implementation
8) Tech Stack

Python · Pandas · NumPy · Matplotlib · Scikit-learn · Jupyter Notebook
